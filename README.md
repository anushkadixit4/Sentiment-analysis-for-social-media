# Sentiment-analysis-for-social-media

This project performs sentiment analysis on social media posts to classify them as positive, negative, or neutral. It leverages machine learning algorithms including Support Vector Machine (SVM), Random Forest, and XGBoost to achieve accurate sentiment predictions.

# Features

-  Preprocessing of social media text data (cleaning, tokenization, stopword removal)
-  Sentiment classification using SVM, Random Forest, and XGBoost
-  Comparison of model performance with metrics like accuracy, precision, recall, and F1-score
-  Visualization of sentiment distribution and model evaluation

# Technologies Used

-  Python for data preprocessing and modeling
-  Scikit-learn for SVM and Random Forest
-  GBoost for gradient boosting-based classification
-  Pandas & NumPy for data manipulation
-  Matplotlib & Seaborn for visualization
